Devices side changes:
==============================
-Update battery info every second when device is charging
-audio: Fix mic issues in apps like WhatsApp
-audio: Fix low mic volume on VoIP
-Enable ADPF CPU hints for improved UI performance :- improving overall UI responsiveness and frame pacing on Snapdragon devices.
-Enable VoNR Calls support
-rootdir: Restrict apps access to /proc/net/unix :- for some banking apps
-Set game refresh rate override to 120
-Compile HWUI for performance 
-properties: Use HintManager for HWUI
-prop: Add a property to enable prefetching video :- improve playback performance for high frame-rate and high bitrate content
-Disable debug.sf.latch_unsignaled :- Disabling this helps reduces notification QS lag, UI performance is not impacted.
-properties: Enable support for kernel idle timer
-Disable Skia tracing by default
-overlay: configure SQLite to operate in MEMORY mode
-Add prop. to save battery life
-rootdir: Fix the battery drain due to statsd
-overlay: Disable alpha compositing in WM :- Completely eliminates occasional jank in few animations
-props: Disable vsync for CPU rendered Apps
-props: Enable config_avoidGfxAccel :- reduces RAM usage and gives better smoothness in the UI.
-Push 120 FPS for ScreenRecorder :- switch manually to 60fps if causes heating/issues
-overlay: Optimized auto brightness adjustment
-enable DC Dimming (to be tested)
